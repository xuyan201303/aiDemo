# 明示承認による累計上限の変更

2026-09-11、ユーザー指示「openai最大30次，改成最大100次。」に基づき、既存の承認ID sanzo-three-file-mock-sdk-v1 の累計上限を30から100へ変更する。使用済み回数・試行履歴・モデルgpt-5.6-terra・三つの架空資料の許可範囲・資格情報の取扱いは保持する。追加100回ではなく、全プロセス/再起動/失敗を含め合計100回まで。

非秘密設定JSONと一度限りの006 data migrationをそろえる。既存の保護triggerは通常更新で上限変更/リセットを引き続き拒否する。migration内では専用grantを検証し、テーブルの排他ロックと単一transactionの中だけ対象triggerを一時停止してmax_requestsのみ更新、直ちに有効化する。migration失敗時は変更/trigger状態を両方rollbackする。新規DBでは対象grantなしなら更新せず、承認済み設定100で作成される。旧migrationや旧証拠は変更しない。

運用時のモデル切替、自動リトライ、予算自動追加APIは追加しない。今回はAPI実行で確認せず、実PostgreSQL回帰と本機statusの表示/累計・台帳一致で検証する。
